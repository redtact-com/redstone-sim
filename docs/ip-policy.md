# 著作権まわりの運用方針

redstone-sim は **無料の非公式ツール**として公開する。Minecraft の挙動を別実装したものであり、
Mojang / Microsoft とは無関係で、公式に見えるようにもしない。

法務の調査そのものは `docs/research/03_legal-decompile.md` にある (EULA / MSA / 日本の著作権法 /
mappings ライセンスの一次資料を当たったもの)。**本書はそこから落とした「日々の運用ルール」**。

> 弁護士の助言ではない。判断に迷うものは入れない、が原則。

---

## 1. コード

### やってよいこと

- **挙動の別実装**。著作権法 10 条 3 項はプログラムの「解法」を保護対象から外している。
  「どういう条件で何が起きるか」を自分の言葉で書き、TypeScript で書き直すのは問題にならない
- **解析のためのデコンパイル**。30 条の 4 (情報解析) の整理。ただし**成果物はコミットしない**
  (`tools/decompile/out/` は .gitignore 済み)
- **実機の観測結果**。tick 数・信号強度・座標・fixture は**こちらが測ったデータ**なので自由に書ける。
  むしろ主張の根拠として積極的に残す

### やってはいけないこと

- **デコンパイルしたコードの逐語引用**。1 行でも「Java の字面の写し」は避ける。
  コメント・コミットメッセージ・PR 本文・issue すべてで同じ
- デコンパイル済みソース・難読化解除済み jar・mappings 実物のコミット

### 典拠の書き方

```ts
// ✗ 逐語引用
// [確定: 26.2 X] `if (!state.getValue(POWERED)) level.scheduleTick(pos, this, 2);`

// ✓ クラス名・メソッド名・バージョン + 自分の言葉 + 実測
// [確定: 26.2 X.updateShape — 消灯中に限り 2gt の tile tick を予約する]
// [実機 fixture observer-pushed: t5 着地 → t7 に powered=true]
```

**情報は減らさない**。クラス名・メソッド名・条件・具体値 (フラグ 2 / 優先度 -1 / 遅延 2gt など) は
事実であって表現ではないので、そのまま残してよい。

## 2. アセット (テクスチャ・モデル・音)

**再配布ライセンスが無いものは同梱しない**。これが一番踏みやすい。

| 種類 | 扱い |
|---|---|
| Mojang のテクスチャ・モデル | **同梱しない**。ミラーから実行時に取得するか、自前アートに置き換える |
| 第三者のリソースパック | **明示の再配布許諾が無ければ同梱しない**。クレジットを書いても許諾の代わりにはならない |
| 自前で描いたアート | 自由。**配布物としては一番安全**で、スマホでの見やすさも自分で決められる |

### 現状 (2026-08-20 時点)

- `app/public/resourcepack/` に **MK.2 Redstone** (by Kyouju and Nisai) を 313 枚同梱し、
  rdsim.com から配信している。**作者の了解のもとで同梱している** (作者はプロジェクト所有者の知人)。
  redstone-maker も同じパックの一部を `public/mk2/` に vendoring している
- 無い場合はバニラテクスチャ ([misode/mcmeta](https://github.com/misode/mcmeta)) に
  自動フォールバックする実装がある

> 口頭の了解はあるが、**許諾の範囲を `credit.md` に書き残しておく**とあとで揉めない
> (誰が・どのパックを・どの用途で・再配布可か)。第三者が fork したときの扱いも決めておくとよい。

**新しく third-party のアセットを足すときは、許諾を取ってから**。クレジットは許諾の代わりにならない。

---

## 3. 見せ方

- **公式に見えるようにしない**。EULA はツール・サービスの開発を許容しているが
  "as long as they do not seem official or approved by us" が条件
- Minecraft のロゴ・書体・公式ブランディングを使わない
- **無料で提供する**。ゲーム本体のコンテンツを使った商用利用は禁止されている
- サイトに「非公式。Mojang / Microsoft とは無関係」と明記する
